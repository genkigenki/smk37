// same brain, twice the hands

The FM-1 has grown up.

The M-Vave FM-1 and the SMK-37 run the same JieLi AC791N chip, the same boot chain and the same update loader. Only the panel is wired differently. So every open FM-1 firmware can run on the bigger keyboard, once it learns the new panel: a thin board layer adds the keys, pads, faders, wheels, LEDs and flash map.

// the lineup · install from the browser

Pick a firmware. Press install.

Firmwares made for the SMK-37, and FM-1 firmwares ported to it. Connect the SMK-37 by USB, open this page in Chrome or Edge, and switch firmwares in about a minute.

FM-1 builds of my own firmwares. They install on an FM-1 only; the keyboard is recognised when you press Connect. Back to the factory firmware: M-Vave's updater, M-UPGRADE, with the FM-1 firmware.

// help

If something goes wrong.

Find what you see, top to bottom. Most of it is fixed with one more install.

  1. An install stopped part way (cable, power, closed tab) Nothing serious. Plug the keyboard in, open the firmware page, press Connect, then Install again: it goes on where it stopped.
  2. It hangs at "switching to update mode" from M-Vave's firmware The first install needs M-Vave's V016. On V013 or V015, update with M-Vave's updater (M-UPGRADE) first. Connect on the firmware page shows which version runs.
  3. The new firmware does not start (dark, or restarting) Hold OCTAVE− and OCTAVE+ for 5 s: most firmwares here open their update mode. Then install again, or go back to M-Vave's firmware (on the firmware page; it also finishes from update mode).
  4. The keyboard is in another firmware's update mode Switch it off and on: its firmware starts again. Or finish that update with that firmware's own updater or M-UPGRADE.
  5. Back on M-Vave's firmware, every key reads "C" and the synth is silent Its key mapping is damaged. Use Repair at the end of this page: it rebuilds the mapping and keeps your calibration.
  6. Black screen, and the computer sees a USB disk "WL82 UBOOT1.00" That is the chip's own download mode; the keyboard is not lost. Don't use the FM-1's factory files on an SMK-37. Ask in the community or on GitHub first, with what you did last.
  7. Still stuck? Every install window has Copy log. Paste it into a message on GitHub or the feedback box. For tinkerers: m-bootloader adds a recovery menu and download mode from the keys (back up first with M-Flasher).

Back to the M-Vave firmware

Our firmwares keep your keyboard's model name, so M-Vave's own updater, M-UPGRADE, works directly.

If your keyboard runs another firmware that M-UPGRADE refuses:

  1. Download the official firmware (.fwsc) for your keyboard:
    SMK-37 Pro: download V016
    SMK-37 Elite: download V016
    Other models: M-Vave's download page.
  2. Drop it here.
  3. Install.

Your keyboard's calibration and pairing are never touched. The firmware on the keyboard, and what it saved, is replaced. Keep the USB cable connected and this tab open until it says Done. Afterwards, M-UPGRADE should also work again if you need it.

If something goes wrong

An install that stopped, a keyboard that does not start, or every key reading "C" on M-Vave's firmware: step-by-step help, and a repair for the key mapping.

Step-by-step help

Repair: every key reads "C" on M-Vave's firmware · 10 min

The page rebuilds M-Vave's key mapping and keeps your keyboard's own calibration, wheel settings and Bluetooth pairings. It installs a small repair firmware and M-Vave's V016, twice each, all by itself: about 10 minutes.

chrome://flags/#use-winrt-midi-api 2. Set Use Windows Runtime MIDI API to Enabled and press Relaunch. 3. Switch the keyboard off and on, then come back to this page.

The repair firmware copies the calibration, wheel values and pairings to a free area, lets M-Vave's firmware rebuild a clean mapping, then puts them back. It fills those areas only when they are empty. The M-Vave file comes from M-Vave; this page never hosts it. Source: smk37-repair (MPL-2.0).
