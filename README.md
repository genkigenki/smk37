# SMK37

The website at **[genkigenki.github.io/smk37](https://genkigenki.github.io/smk37/)**: open FM-1 firmwares on the
M-Vave SMK-37 Pro, installed from the browser (Chrome or Edge, USB cable).

| Firmware | What | Source |
| --- | --- | --- |
| Makkuro37 | a microtonal drone synth ([simulator](https://genkigenki.github.io/smk37/makkuro37-sim/)) | [genkigenki/Makkuro37](https://github.com/genkigenki/Makkuro37) |
| Snoop37 | SLOOP by isod89, with the SMK's pads, faders and wheels | [genkigenki/Snoop37](https://github.com/genkigenki/Snoop37) |
| X0X37 | X0X by Charles Vestal | [genkigenki/X0X37](https://github.com/genkigenki/X0X37) |
| FoMni37 | FoMni by Charles Vestal | [genkigenki/FoMni37](https://github.com/genkigenki/FoMni37) |

Port your own FM-1 firmware: [fm1-to-smk37](https://github.com/genkigenki/fm1-to-smk37).

This repository is the built site: the page, the installer (from Felucca / SLOOP, GPL-3.0) and the firmware
packages of the projects above, each under its own license. Unofficial, not affiliated with M-Vave. Install at
your own risk.
